SPIKE-004 — how to take a reading that means something

1. Set the geometry first

A 45° fold makes the light path eye → pane → down to screen. That is longer than looking straight at the phone, and it is the reason a "smallest legible size on the bare screen at arm's length" number is not comparable to the same number through the glass: the difference would be part distance and part optics, and the whole of it would get blamed on the optics.

  • D = eye to the pane, horizontally, in cm.
  • w = depth of the screen strip the pane covers, in cm.
  • The folded path is about D + w/2. Set both with the D+ / w+ buttons before the first mark (they wrap).

2. Take the baseline (no glass needed)

Switch layout to baseline. Lay the phone flat and look straight down at it — the folded path meets the screen along its normal, so a head-on view is the matching one, not an angled one. Put your eye D + w/2 above the screen. Run the tests and MARK.

3. Take the ghost reading (needs the reflector)

Switch layout to single for one pane, or pyramid for a four-face frustum. Set the room dark, screen brightness at max, screen timeout to never. If the ghost reads upside down, press flip — that settles whether the frustum is small-end-down or large-end-down without anyone having to work it out.

4. What each test wants

  • glyph height — step DOWN until it stops being readable, then step back up one and MARK. The mark is the smallest legible size.
  • colour survival — MARK the last swatch set where every patch is still distinguishable.
  • viewing arc — walk around the pyramid (or side to side for one pane) and MARK while reading off the spoke where the image breaks. Put the degree number in the note when you report it.
  • element density — MARK the highest count where every cell is still readable, not most of them.
  • ambient ceiling — the screen is fixed here. You change the room light and MARK at the point the ghost washes out.
  • motion legibility — MARK the fastest drift still readable.
