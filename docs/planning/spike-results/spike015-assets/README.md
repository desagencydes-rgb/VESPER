# spike015-assets

The `SPIKE-015-*.json` results in the parent folder name `screen.png` here as the
image the vision rungs were asked to describe. **That file was removed before
the repository was made public**: it was a full-resolution capture of the
original owner's own screen, with personal material on it.

The measurements are unaffected — they are recorded in the JSON files. To re-run
the probe (`tools/spike/model_capability_probe.py`), put any screenshot of your
own at `spike015-assets/screen.png`. Expect different descriptions; the
throughput and tool-call figures are what the spike compares.
