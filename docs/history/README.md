# docs/history — the project's diary

Dated plans, handoffs, session notes and overnight reports from August to
November 2026, moved here from the repository root when VESPER went public.
They are kept because the reasoning in them is part of the record: why
something was built the way it was, what was measured, and what went wrong
first. They are **not** current instructions -- for what is true now, read
`VESPER_OPEN_WORK.md` and `VESPER_ENGINEERING_STATUS.md`.

Commit hashes quoted in these files name commits from the original, private
history; find the matching commit here by its subject line.
