# VESPER V0 — Team, Agent & Authority Model
Version 1.0

## 1. Stable roles, replaceable tools
Roles define responsibility. Tools and models are replaceable.

## 2. Project Owner
Owns immutable source requirements, final acceptance, high-impact security decisions, budget policy and unresolved architectural disputes.

## 3. Chief Architect / System Integrator
System boundaries, cross-plane architecture, ADR approval, interface integrity, dependency direction, source-to-architecture traceability.

## 4. Core Systems Engineer
Runtime lifecycle, event bus, IPC, supervision, persistence primitives, configuration and resource governor.

## 5. Intelligence Systems Engineer
Model gateway, routing, context budget, planner, verifier, orchestration and reasoning services.

## 6. Knowledge & Memory Engineer
BAG/project maps, memory schema, retrieval, provenance, indexes and artifact registry.

## 7. Perception Engineer
Audio, vision, screen perception, OCR and media evidence pipeline.

## 8. World & Environment Engineer
World model, device graph, spatial topology, room/space model and capability graph.

## 9. Presence & Interaction Engineer
Speech, listening, semantic scenes, projector/glass/spatial adapters and desktop/phone surfaces.

## 10. Autonomy & Task Engineer
Event-driven initiative, task graph, schedules, background operation, checkpoints and stop conditions.

## 11. Device / Network Engineer
Device registry, node identity, secure network, discovery and health.

## 12. Security Engineer
Authentication, authorization, secrets, isolation, audit, anomaly detection, containment and recovery.

## 13. Verification Engineer
Acceptance tests, contracts, regression, fault injection, benchmark harness and release evidence.

## 14. Research Engineer
Feasibility studies, new models, sensing, interaction and reproducible experiments.

## 15. Tool assignment
Claude Code: deep repository implementation/debugging.
Kiro: spec-driven planning and implementation.
Antigravity: asynchronous/parallel agentic execution, browser-assisted work and end-to-end research.
Cursor: interactive exploration, focused edits and controlled background agents.
VS Code: human inspection, debugging, review and final integration.

## 16. Separation of duties
Architect designs; implementer implements; verifier tests; owner accepts high-impact changes. No agent approves its own security boundary.

## 17. Parallelism
No artificial agent-count ceiling. Actual concurrency is bounded by hardware, resource budget, dependency graph, isolation, model availability and policy.

## 18. Agent identity
Every run receives role, task ID, branch/worktree, capabilities, model/provider, resource budget, time budget and source IDs.

## 19. Escalation
Escalate source infeasibility, interface changes, security-boundary changes, migrations, unclear rollback, conflicting benchmark evidence or major architecture alternatives.
