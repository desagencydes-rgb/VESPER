## Build invariant
VESPER is a persistent distributed operating presence. Models are workers, devices are nodes, interfaces are contracts, and identity/state/capabilities/continuity survive model or device replacement.

## Implementation readiness
A subsystem is implementation-ready only when requirements, interfaces, ownership, security boundary, persistence, observability, failure behavior, acceptance tests, and rollback are defined.
