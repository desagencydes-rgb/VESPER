Project status · 8 November 2026

Where things stand.

A map of what you can rely on, where the build breaks, and where a contributor can change the answer.

Done

What you can build on

Foundation and memory
The spec, contracts, state machines and governed memory system are built. Acceptance suites exercised the runtime and network fabric on Windows and Linux.
Action and evidence
The runtime can take contained, checkpointed actions under two-axis authority. The showcase has panes, marks, a cursor, a browser, a whiteboard and a live run tail.
On the Desktop
Globe ×3 calls VESPER to the current Desktop. The showcase follows the owner’s screen. The app can reopen after a grant without invalidating its own signature.
Busy Desktops
The 8 November evening record confirms the full-screen showcase was driven on a busy Desktop and the home landed on an empty second display.
Broken

Where behavior breaks

Showcase layout
Panes can collapse into a shallow strip. Structural readback counted the panes while missing their size.
Voice selection
The runtime computes a voice and discards it. The host default speaks instead, and the speech egress check is red.
Speaking blocks the pump
On 16 September 2026 a 19-word sentence held the runtime for 6.1 seconds. It could neither hear nor act while the sentence played.
Spoken latency
On 8 November 2026 one spoken turn took about 30 seconds to reach the screen. Capture duration, startup and provider selection each need measurement.
Unfinished

Where a first patch fits

Voice and typing
The queued voice worker exists but has no callers. Focus and scroll have been exercised through the accessibility bridge. Typing into a real field still needs proof.
Verification by image
The app can photograph its own window. The showcase and UI harnesses still need to assert pane size and position from the image.
Scene composition
The showcase runs hand-authored scenes. Composing a different scene for each situation needs a working model rung.
Pending checks
On 9 November 2026 the registry listed 18 of 207 checks as PENDING, with 10 more runnable checks outside the registry. Each needs an executed negative control.
Other desktops
Windows and Linux run the core and gates. The Tauri home and showcase shell is open work.
Not solved

Where an experiment is needed

A Desktop of its own
VESPER may be summoned to a busy Space, but will only take an empty one unasked. Finding an empty Desktop still depends on the user.
Foreign windows
macOS would not move another app’s windows between Spaces in the recorded probes. Accessibility can drive only the visible Desktop, and a new window can land elsewhere.
Permission identity
Which macOS grants survive an ad-hoc rebuild remains unresolved. A Developer ID would give the app a stable identity.
Hearing through music
The recorded voice-processing path exposed a channel layout the recogniser rejected. Listening pauses while another app plays sound.
